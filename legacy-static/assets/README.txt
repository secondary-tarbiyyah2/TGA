These are LICENCE-FREE STOCK IMAGES used for launch (sourced from Unsplash,
free for commercial use, no attribution required). Swap them for real Academy
photography when it's available — keep the same filenames and no code changes
are needed.

  hero.jpg      900 x 1299, portrait. Open book + study notebook (warm, no people).
                Sits inside the arch frame in the hero.
  band.jpg      1400 x 788. Islamic geometric dome — background of the full-bleed

To replace: drop in a new file of the same name (similar aspect ratio is ideal).
A woven-texture CSS fallback is kept behind band.jpg in case it ever fails to load.

No other assets are required — fonts load from Google Fonts and all icons/motifs
are pure CSS.
